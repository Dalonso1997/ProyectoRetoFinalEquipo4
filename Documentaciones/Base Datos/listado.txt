*(Filtrado para contener exclusivamente elementos puros de soldadura)*

**Soldador de lápiz** - Herramienta eléctrica con punta metálica para calentar los terminales de los componentes.

**Hilo de estaño** - Carrete de metal de aportación que se funde para realizar las uniones eléctricas.

**Cable SATA de datos** - Cable plano interno para comunicar unidades de almacenamiento con la placa base.


*

* 
**Cable de alimentación ATX (IEC)** - Cable de corriente externo para dar suministro desde el enchufe a la fuente de alimentación.


* 
**Cable de alimentación Molex** - Cable interno de la fuente para alimentar componentes complementarios o antiguos.

Memorias RAM

**Soporte metálico para soldador** - Base pesada de seguridad donde descansar el soldador mientras permanece caliente.


* 
**Módulo de memoria RAM DDR4** - Memoria de acceso aleatorio para prácticas de montaje en placas base modernas.


* 
**Módulo de memoria RAM DDR3** - Memoria de acceso aleatorio destinada al mantenimiento de equipos informáticos anteriores.

**Disco duro SAS** - Unidad de almacenamiento magnético de alta velocidad orientada a servidores de prácticas.

* 
**Tarjeta de red Ethernet PCI** - Tarjeta interna para añadir un puerto de conexión por cable RJ45 adicional.

**Tarjeta de red Wi-Fi PCIe** - Tarjeta de expansión con antenas externas para dotar de conectividad inalámbrica al PC.


* 
**Tarjeta gráfica de interfaz AGP** - Componente de vídeo antiguo para el estudio de arquitecturas de hardware clásicas.



### **Cajón 2: Pasta térmica** 

* 
**Jeringa de pasta térmica gris** - Compuesto con base metálica para optimizar la transferencia de calor en el procesador.


* 
**Jeringa de pasta térmica de silicona** - Compuesto conductor básico de color blanco para disipadores estándar.


* 
**Almohadilla térmica (Thermal pad)** - Lámina conductora sólida y recortable para chipsets o fases de alimentación.


* 
**Tubo de pasta térmica cerámica** - Compuesto disipador cerámico libre de conductividad eléctrica para evitar cortos.



### ### Cajón 3: Fuentes de alimentación | 

Herramientas: Destornilladores, tijeras 

* 
**Fuente de alimentación formato ATX** - Componente eléctrico principal para energizar los componentes de la torre.

**Fuente de alimentación formato SFX** - Suministro de energía en formato compacto diseñado para chasis de tamaño reducido.


*

* 
**Crimpadora de impacto** - Herramienta de inserción para fijar de forma individual los hilos de red en las rosetas murales.


* 
**Crimpadora de red multifunción** - Herramienta universal con guías de corte apta para conectores RJ45, RJ11 y RJ12.
